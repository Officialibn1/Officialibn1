## Experience

### Full-Stack Developer · Trade Modernization Project (TMPL)
*Hybrid, NCS Partner · Aug 2025 – Present*

- Rebuilt the frontend of the **B'Odogwu Revenue Reporting System** in Next.js, TypeScript, and Tailwind CSS to fix slow page loads and unresponsive data queries reported by customs officers. Report views now navigate in under a second, using route-based code-splitting and skeleton loading states.
- Improved data-fetching reliability with **RTK Query** caching, cutting redundant API calls and speeding up repeat views. Built data display with Tanstack Table and revenue visualizations with Recharts.

### Full-Stack Developer · Nigeria Customs Service Headquarters
*Onsite, NYSC · Sep 2024 – Aug 2025*

- Designed and built a **Digital Mail and File Tracking System** (Next.js, TypeScript, Prisma ORM, PostgreSQL) to replace a manual, paper-based logging process. File lookups dropped from up to an hour to milliseconds, and records are no longer lost to misplaced logbooks.
- Scaled the system to **5,000+ file records and 4,200+ mail records** across **150+ officers, 98 offices, and all 14 departments**. I ran workflow sessions with officers to turn the paper process into accurate data models and permissions.
- Added full **audit-trail logging** that captures every user and action as a file moves between offices, giving a complete, queryable history for every record.

### Freelance Full-Stack Developer
